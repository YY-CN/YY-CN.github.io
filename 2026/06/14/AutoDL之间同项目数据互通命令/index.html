🔍 参数深度解析

参数 作用说明
-a (archive) 归档模式。保持文件的所有属性（权限、时间戳、软链接等）不改变。
-v (verbose) 详细模式。在终端打印当前正在传输的文件列表和进度。
-z (compress) 传输时压缩。在网络传输过程中对数据进行压缩，节省带宽，提高传输速度。
-P (progress) 显示实时传输进度条，并支持断点续传（对大文件非常重要）。
-e "ssh -p ..." 指定远程连接使用的协议和非标准端口（AutoDL 必须指定端口）。

⚠️ 避坑指南：必须注意的「斜杠 /」细节

rsync 对路径末尾的斜杠 / 极其敏感，不同的写法会导致完全不同的结果：

  1. 正确写法（推荐）：源路径和目标路径末尾都带斜杠
    • 示例：...:/root/project/ /root/project/
    • 效果：将 B 实例 project 目录内部的内容，同步到 A 实例的 project 目录内部。
  2. 错误写法：源路径末尾不带斜杠
    • 示例：...:/root/project /root/project/
    • 效果：会在 A 实例的 project 目录下再创建一个 project 目录，变成了 /root/project/project/。

1. 排除特定目录（不全量同步）

如果你不想同步 weights/（权重文件）或 dataset/（原始数据集，因为已经有了），只想同步代码和日志，可以使用 --exclude 参数：

Bash

2. 双向完全对齐（谨慎使用）

如果 B 实例中删除了某些没用的临时文件，你希望 A 实例也跟着删除，保持完全一致，可以加上 --delete 参数。

  • 警告：这会删除 A 实例中存在但 B 实例中没有的文件，执行前请务必确认！
