👨‍💻 关于我

我是一名专注于计算机视觉、信息安全与多模态分析领域的探索者。这个博客是我记录学术笔记、实验踩坑日常以及分享阅读心得的数字花园。我喜欢通过代码和实验来验证新想法，也热衷于探索前沿的技术与论文。

🔬 研究与兴趣方向

  • 多模态欺骗检测 (Multi-Modal Deception Detection)： 致力于通过视觉、听觉等多维度特征进行行为分析与检测。
  • 计算机视觉与行为分析： 专注于面部特征提取、动作单元分析及情感计算。
  • 前沿学术追踪： 持续关注信息取证与安全领域的最新进展，常出没于 ACM Digital Library、IEEE TIFS 等顶级学术会议与期刊。

🛠️ 技术栈与工具

  • 核心工具： OpenFace 等开源计算机视觉和面部分析工具库。
  • 开发与部署： Git / GitHub (熟练处理各类 SSH 连接问题)、Linux 环境配置。
  • 数据与实验： 熟悉多模态开源数据集（如 DOLOS）的处理、特征对齐与模型训练。

📈 近期在做的事

  • 跑实验：针对特定的多模态数据集设计并验证算法。
  • 读论文：拆解 Spatio-Temporal Disentanglement 等复杂模型架构。
  • 写代码：优化特征提取流程与开源工具的二次开发。
